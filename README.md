qtMUD is the Group's Python 3 engine for developing and hosting MUDs
(Multi-User Dimensions): a socket server (`qtmud_run`) that clients reach by
telnet or a MUD client such as TinyFugue. It is distinct from QTOps, whose
earlier Racket and Fennel source is archived in the parent section's
`lib/legacy/`.

This repository is qtMUD's one home. It is mounted at `apps/qtmud/` of
[Computer MUD Engineering Services Section](https://github.com/red-cup-engineering/computer-mud-systems-engineering-services-section),
beside MOOSE.

## Earlier work

qtMUD was previously developed at `github.com/emsenn/qtmud` (no longer
resolvable), published to PyPI as `qtmud` (0.0.5 is the last version the
archived README shows), documented on Read the Docs at `qtmud.readthedocs.io`,
and discussed on Gitter at `gitter.im/qtmud/Lobby`.

`lib/legacy/2026-08-17-emsenn-drive-backup/` holds the qtMUD README recovered
from the 2026-08-17 Google Drive backup, kept as received.
